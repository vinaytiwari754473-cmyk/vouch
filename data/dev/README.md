# Vouch development dataset

This directory is generated by `@vouch/generator`; do not hand-edit its data files.

- `public/` contains the three inputs available to the reconciliation engine.
- `truth/manifest.json` contains hidden labels for evaluation only and must never be imported by
  `@vouch/core` or bundled into the product UI.

Regenerate deterministically with:

```sh
pnpm --filter @vouch/generator generate:dev
```

All records are synthetic. No real merchant, customer, payment, or bank data is present.
